# OshiLogでは何を確認できるか

初めてOshiLogを見る企業の評価者向けの案内です。記録一覧・検索・期間集計から、アプリの価値と確認済みの範囲を把握できます。

記載日：2026年10月28日。既存資料と保存済み検証記録に基づきます。

開発環境の構築手順は[README](../README.md)、今回の局所検証は[QA追記](issue-31-qa.md#2026-10-28-企業提出向け検証)を参照してください。

## 目的と現行MVP

OshiLogは、推し活を「記録する・振り返る・可視化する」Ruby on Railsアプリです。

| 価値 | 現にある機能 |
|---|---|
| 記録する | 活動日・カテゴリ・タイトル・推し・金額・メモ等の活動記録 |
| 振り返る | 活動履歴、年月・推し・カテゴリ・キーワードによる絞り込み |
| 可視化する | 年・推しを選んだ活動回数、支出、月別活動、カテゴリ割合等の集計 |

## 既存データを見る操作案内（目安3分）

[公開URL（README記載）](https://13.115.187.119/)は記録済みの参照先です。この案内の作成時には、公開サイトの動作や閲覧用入口の稼働を新たに確認していません。

提供者が案内した既存の閲覧用入口を利用し、ログイン済みの状態から始めてください。入口が不明、ログインできない、証明書や認証に関する警告が出る場合は操作を止め、提供者へ確認してください。資格情報はこの資料に記載しません。

以下は既存画面・経路に基づく案内で、公開環境での通し操作は未確認です。時間は目安で、アカウント作成や記録の新規作成・編集は行いません。

| 目安 | 操作 | 見る点 |
|---|---|---|
| 0〜1分 | 「活動記録一覧」を開き、既存の記録を選んで詳細を見る。一覧に戻る。 | 日付・カテゴリ・推し・メモ等を記録として確認できるか。記録が表示されなければ提供者へ確認する。 |
| 1〜2分 | 一覧で見たタイトルの一部を「キーワード」へ入力し、「絞り込む」。推しで絞る場合は「推し」の選択欄を使い、最後に「条件をクリア」。 | キーワードはタイトル・場所・メモを検索する。推し名の検索とは別で、条件と結果を確認できるか。 |
| 2〜3分 | 「トップ」→ホームの「詳しいデータを見る」を開く。「期間」と「推し」を選んで「表示する」。 | 活動回数・支出・月別活動・カテゴリ割合を確認する。月別の件数リンクから該当する活動一覧へ移れるか。 |

## 本人の判断とAI支援

- 本人側：ヒアリングによるMVPの絞り込み、機能優先度の判断、自分での画面確認。
- AI支援：AWS構築・実装・診断・テストで大きく活用しています。テストの設計・実行・原因調査もAIの支援を受けています。

開発者本人の目標は次のとおりです。達成済みの実績として掲げるものではありません。

> 必要な人に必要な便利さを届けることができるようになるのが目標
