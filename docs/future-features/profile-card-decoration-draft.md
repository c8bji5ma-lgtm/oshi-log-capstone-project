## 1. 目的・位置づけ

AIで生成したプロフィールカードを、プリクラの落書き機能のように自分好みに装飾できるようにする。

「推し活の記録を、自分らしいプロフィールとして表現する」という方向性を補強するための拡張機能。プロフィールカードのAI生成方式自体は、このメモでは定義しない。

既存のMVP（記録・振り返り・可視化）とは切り離し、将来機能として検討する。既存の確定仕様・テーブル定義・画面遷移には今回変更を加えない。

## 2. 今回の会話で合意した機能範囲

| 区分 | 機能 | 内容 |
| --- | --- | --- |
| ペン | 手書き描画 | カードの上に自由に線を描く |
| ペン | 線の色 | ユーザーが選択できる |
| ペン | 線の太さ | ユーザーが選択できる |
| ペン | 種類 | **通常・蛍光・ラメ・ネオン**の4種類を用意する方針 |
| ペン | ラメ表現 | 線に沿ってキラキラした粒子・質感を表現する方向 |
| ペン | ネオン表現 | 線が発光して見える表現を用意する方向。ラメとは別の効果 |
| スタンプ | 配置 | 用意されたスタンプを選び、カード上の好きな位置に置く |
| 文字 | テキスト追加 | カードに任意の文字を入力・配置する |
| 文字 | 装飾 | 文字の**色・大きさ・太さ**を選択する |
| 編集 | 元に戻す | 直前の編集操作を取り消す |
| 出力 | 画像保存 | デコレーション後のカードを1枚の画像として保存する |

### ペンの基本方針
- ペンの種類と、色・線の太さの設定を分ける。
- 色と線の太さは4種類のペンで共通して変更できる設計を目指す。
- **ラメ**と**ネオン**は別の描画効果として扱う。

### 操作イメージ（仮）
1. 作成済みのプロフィールカードを開く。
2. ペン・スタンプ・文字から編集方法を選ぶ。
3. 色・太さなどを選んでカードに装飾を追加する。
4. 必要に応じて「元に戻す」を使う。
5. 完成したカードを画像として保存する。

## 3. 実装上の方向性（提案段階）

- ブラウザ上の描画技術として、HTML Canvasなどを候補とする（技術選定は未確定）。
- スマートフォンでのタッチ操作を想定し、描画・オブジェクト操作・画像出力を個別に検証する。
- ラメとネオンは処理・見え方が異なるため、通常ペンより実装・性能検証の負荷が高いと見込む。
- 装飾状態を編集可能なデータとして保存するか、完成画像だけ保存するかは未決定。
